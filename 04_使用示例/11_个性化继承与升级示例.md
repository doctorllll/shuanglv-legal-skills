# 个性化继承与升级示例

场景：旧用户在 v0.41 已形成“正式文书不要一句话一段、默认 DOCX”的个人习惯。v0.42 新增文书成文策略，但不应覆盖上述习惯。

升级后的有效优先级：

```text
Core 硬规则：事实与法律核验不可关闭
Matter：某案件要求所有称谓统一为“申请人/被申请人”
User：避免一句话一段；默认 DOCX
v0.42 Default：文书重写按需要采用结构性重写
```

系统应自动保留 User 与 Matter 设置，只在用户设置与不可覆盖硬规则冲突、旧设置失效或无法迁移时提示。

用户要求“把我的个性化全部列出来”时，应展示人类可读清单，而不是要求用户理解 JSON Schema。
