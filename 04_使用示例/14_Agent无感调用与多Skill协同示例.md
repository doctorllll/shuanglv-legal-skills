# Agent 无感调用与多 Skill 协同示例

用户直接说：

> 帮我审一下这份采购合同，重点看付款和验收，直接给我修改稿。

用户没有说“调用爽律”。在支持自动 Skill 选择且 `activation.mode=AUTO` 的环境中，应静默激活爽律，主路由到“合同与交易工作”；需要正式 DOCX 时，再向当前 Agent 请求 DOCX 输出能力。

关键点：

- 自动激活只省掉“喊 Skill 名称”这一步；
- 合同事实、风险、修改逻辑仍按爽律合同工作流；
- 用户已有模板仍优先于系统默认；
- Office 能力负责做文件，不替代法律内容判断；
- 如果宿主不支持自动 Skill 发现，则应明确这是平台边界，不伪称无感调用已发生。
