# 爽律 Skill｜律师专业工作流系统——技能总览与人工核验入口

系统中的每个技能现在都分成两种阅读层：

- **人工核验层**：先读《详细说明与工作流程》，完整理解这个技能是什么流程、用了什么方法、什么时候转人工、产出什么。
- **Agent 执行层**：再读《技能定义》《业务模块汇总》《核心规则汇总》《检查清单汇总》和必要数据结构。

## 方法成果到底在哪里

技能方法分别固化在：

1. **《详细说明与工作流程》**：给人看的完整方法地图；
2. **《技能定义》**：Agent 的调用条件、边界、输入输出和总流程；
3. **《业务模块汇总》**：每一步具体如何执行；
4. **《核心规则汇总》**：必须遵守的规则、门控和禁止事项；
5. **《检查清单汇总》**：执行完成前的质量控制；
6. **数据结构**：稳定传递事实、证据、研究、风险和交付状态。
