# 技能调度规则

## 一、基本原则

一次任务应确定一个**主技能**。辅助技能只在确有必要时调用，不为了形式完整而把所有技能串起来。

## 二、主技能选择

| 用户任务 | 主技能 |
|---|---|
| 法律检索、案例检索、法律问题深度研究 | 法律研究与多源资料融合 |
| 刑事案件办理、会见、阅卷、证据、辩护 | 刑事案件办理 |
| 民商事诉讼或仲裁、请求抗辩、举证策略 | 民商事争议解决 |
| 合同起草、审查、修订、交易结构 | 合同与交易工作 |
| 法律咨询、专项分析、法律意见 | 法律顾问与专项法律分析 |
| 尽调、专项事实调查 | 尽职调查与专项调查 |
| 已有法律内容的结构、语言、格式和交付质量控制 | 法律文书质量与格式控制 |

## 三、辅助技能何时调用

### 多模态输入适配（可选）
仅在当前 Agent 或用户已有工具不能可靠读取文件，或者不能满足页码、时间戳、表格结构等输入质量要求时调用。

### 法律研究与多源资料融合
业务技能遇到以下情况时调用：
- 现行法需要核验；
- 需要权威案例；
- 法律规则可能已经变化；
- 需要寻找反向观点、例外或边界。

### 法律文书质量与格式控制
以下情况调用：
- 需要正式对外交付；
- 用户要求生成 DOCX、PDF 等正式文书；
- 已有草稿需要做结构、语言、引用、格式或版本质量控制。

## 四、跨技能交接

跨技能时至少传递：
1. 本次任务目标；
2. 已收到和实际审阅的材料；
3. 已形成的事实、问题、分析结果和风险；
4. 对应来源定位；
5. 尚未解决的问题；
6. 下一个技能需要完成的具体任务。

复杂任务优先通过《项目执行说明书》完成交接。

## 五、禁止事项

- 调度规则不代替业务技能做实体法律分析；
- 跨次续接时读取当前可访问的项目记录和相关材料；
- 需要外部资料时使用当前 Agent 已连接且获授权的数据源；
- 没有上一轮记录时，不得假装知道“上次做到哪里”。


## 六、正式交付前公共阶段

重要任务完成主技能工作流以后，不直接交付：

```text
初步结论
→ 统一对抗性审查
→ 必要修正
→ 人工决策与升级检查
→ 正式交付
```

具体审查项目见《统一对抗性审查规范》和各技能目录内《对抗性审查清单》。
