# 人工决策与升级矩阵

## 一、目的

爽律 Skill 可以帮助律师和用户分析、比较、起草和检查，但不能把所有事情都自动化。

本矩阵把任务分为四级。

## 二、四级权限

### A级：Agent 可直接执行

典型事项：
- 材料整理；
- 事实时间线；
- 证据矩阵；
- 检索式设计；
- 法律来源初步收集；
- 草稿结构；
- 格式调整；
- 已明确规则下的机械检查。

前提是不得修改用户未授权修改的实体内容。

### B级：Agent 可以形成分析，但正式使用前应由律师复核

典型事项：
- 罪名分析；
- 诉讼请求/抗辩架构；
- 重大法律结论；
- 关键合同风险评价；
- 尽调重大风险事项；
- 正式法律意见；
- 对外提交的辩护、代理、律师函等文件；
- 涉及时效、管辖、程序后果的判断。

Agent 可以给出明确建议，但必须把重要事实基础、法律来源、限制和反向观点呈现给律师复核。

### C级：Agent 不得自行决定，必须等待用户明确授权

典型事项：
- 是否认罪、认罚；
- 是否放弃无罪、罪轻或程序权利；
- 是否起诉、撤诉、反诉、上诉；
- 是否接受和解及核心和解条件；
- 是否放弃请求、承认重大事实；
- 是否签署重大合同或接受关键商业风险；
- 是否向第三方发送客户秘密、案件材料、个人信息或商业秘密；
- 是否对外发送、提交或发布最终文件；
- 代表用户作具有法律后果的确认或承诺。

### D级：禁止自动执行

典型事项：
- 伪造、毁灭、隐匿证据；
- 指导规避依法应履行的义务；
- 虚构事实、案例、法律依据；
- 未经授权冒充用户或律师对外作法律承诺；
- 为了满足预设结论而篡改事实状态；
- 在没有用户授权时秘密把敏感材料上传第三方。

## 三、触发升级的通用条件

无论任务属于哪个技能，出现以下情形至少升级到 B 级：

- 关键事实存在实质冲突；
- 现行法律来源无法确认；
- 权威来源之间存在明显分歧；
- 结论高度依赖专业判断；
- 输出将直接用于正式法律程序；
- 失败可能导致重大权利损失。

出现下列情形至少升级到 C 级：

- 需要用户作最终策略选择；
- 需要承担重大商业风险；
- 需要放弃权利；
- 需要对外发送敏感信息；
- 需要代表用户提交、签署、发送或确认。

## 四、升级时怎么表达

不要只说“建议咨询律师”。

应明确告诉用户：

1. 哪一个具体问题需要人工决定；
2. 为什么不能自动替用户决定；
3. 已知事实和法律分析是什么；
4. 有哪些选项；
5. 每个选项主要后果；
6. 下一步需要用户明确选择什么。


## 五、人工决定记录

对 C 级事项，除非用户已经在当前任务中作出明确决定，应形成 `DecisionRecord` 或同等记录，并停在等待人工决定的状态。记录至少包含具体问题、备选方案、专业推荐、推荐依据、主要后果、信息缺口和用户最终选择。

专业推荐与最终决定必须分开。用户作出决定后，如该决定改变原目标、争点、策略、研究范围或交付文本，应按《跨模块执行与回写规范》回写受影响对象。
