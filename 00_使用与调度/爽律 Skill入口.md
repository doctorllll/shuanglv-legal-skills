# 爽律 Skill入口

> **v0.43 正式版｜Agent Native｜发起及主导：广东卓建律师事务所 蔡诗爽律师**  
> 使用真实案件、客户或交易材料前，应根据敏感程度先进行必要脱敏；本系统只提供专业辅助，不能替代律师最终判断。

**全名：爽律 Skill｜律师专业工作流系统**  
**调用名：爽律**

`system_id: shuanglv-legal-skills`

## 一、激活规则：默认无感调用

在支持 Agent Skills 自动发现的 Agent 中，用户**不需要先说“调用爽律”**。只要任务属于实质性中国法律专业工作，Agent 应依据根目录 `SKILL.md` 的 `description` 自动加载爽律 Skill，再按本入口路由。

例如用户直接说：

> “帮我审一下这个合同，直接改。”  
> “分析这套刑事卷宗，找辩护点。”  
> “查一下这个争议点最近怎么判。”  
> “帮我准备整套起诉材料。”

以上均可直接进入爽律，无需播报 Skill 名称。

旧调用别名继续兼容，并视为显式强制入口：`爽律 / 调用爽律 / 用爽律处理 / 用爽律做 / ShuangLaw`。

用户可通过个性化把 `activation.mode` 设为 `AUTO / CONFIRM / MANUAL`；升级默认保留其明确设置。详细见《自动激活与Agent原生调度规范》。

## 二、自动或显式激活以后怎么做

```text
识别用户任务
→ 判断输入能否可靠读取
→ 确定一个主技能
→ 形成渐进式加载计划
→ 判断是否需要辅助技能
→ 生成本次动态检查清单
→ 必要时建立通用结构化审阅
→ 执行业务工作流 + 分析与推理闭环
→ 复杂任务用稳定对象完成跨模块交接
→ 建立重要事实、证据、法律/案例、论证与交付命题的全链路溯源
→ 对重要任务做统一对抗性审查并回写修正
→ 多方案任务形成策略选项，重大决定停在人工节点
→ 解析法律信源、知识库、文件和交付工具等外部能力
→ 能力不足时等价替代、明示降级或阻断
→ 触发必要的人工复核或明确授权
→ 执行质量门控
→ 根据用户需要形成正式交付物
→ 复杂任务生成项目执行说明书
```

## 三、主技能自动路由

| 任务 | 默认主技能 |
|---|---|
| 法律、案例、规范、观点研究 | 法律研究与多源资料融合 |
| 刑事辩护、被害人代理、控告报案、立案监督、会见、阅卷、证据 | 刑事案件办理 |
| 民事、商事诉讼或仲裁 | 民商事争议解决 |
| 合同起草、审查、修改、谈判和交易支持 | 合同与交易工作 |
| 法律咨询、专项分析、法律意见 | 法律顾问与专项法律分析 |
| 尽调、专项事实调查 | 尽职调查与专项调查 |
| 正式文书结构、语言、格式和交付质量 | 法律文书质量与格式控制 |

“多模态输入适配”不是默认业务主技能，只在当前 Agent 或用户已有工具无法可靠读取输入时选择性调用。

## 四、辅助技能自动调用原则

业务任务需要核验现行法、案例或反向观点时，可以调用“法律研究与多源资料融合”。

需要正式对外交付时，可以调用“法律文书质量与格式控制”。

原始 PDF、图片、音频、视频等无法可靠读取时，才考虑“多模态输入适配（可选）”。

不要为了“显得完整”把所有技能全部调用一遍。

## 五、统一质量门

重要任务在正式交付前至少经过：

1. **事实状态检查**：有没有把陈述、推断或未知写成已核验事实；
2. **来源与现行法检查**：关键法律和资料是否可回查；
3. **全链路溯源检查**：核心结论是否能回到事实、证据、规则/案例和论证；
4. **跨模块交接检查**：研究、分析、策略和后续步骤是否真实连接；
5. **对抗性审查与回写**：主动攻击当前初步结论，并检查发现的问题是否修正原分析；
6. **人工升级判断**：是否存在必须由律师复核或用户明确授权的事项；
7. **交付物检查**：内容、格式、版本和文件能力是否真实。


显式调用别名继续作为兼容入口；在支持 Agent Skills metadata 自动发现的宿主中，专业法律任务可以无感触发。

## 六、工程执行增强

当前运行环境支持本地 Python 时，可以调用 `05_工程执行层/工具/爽律 Skill执行器.py` 生成：

- 执行计划；
- 渐进式加载路径；
- 本次动态检查清单；
- 跨模块交接与回写检查；
- 全链路溯源断链检查；
- 正式交付前质量门控报告。

工程执行器只负责调度和检查，不负责作出实体法律结论。不能运行脚本时，直接按同目录规则文档执行。

## 七、边界

只有当前 Agent 已经安装、加载或能够访问爽律 Skill 时，调用别名“爽律”才有意义。

一个从未加载爽律 Skill 的陌生 Agent，不会因为听到调用别名“爽律”就自动获得这些技能。


## 八、外部能力

调用外部法律信源、用户知识库、文件/OCR 或交付工具时，按 `01_运行规范/外部能力适配规范.md` 处理。系统不绑定具体厂商；未真实调用或无法回查的能力，不得写成已经完成。
