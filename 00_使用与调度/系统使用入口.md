# 爽律 Skill｜律师专业工作流系统——系统使用入口

> 用户直接说“调用爽律”“用爽律做”时，先读取《爽律 Skill入口.md》。

## 一、定位

本系统用于直接交给 Agent 运行。它只包含法律工作需要的技能、规则、调度、交接和输入输出规范。

## 二、使用顺序

1. 先阅读《技能调度规则》，确定一个主技能；
2. 仅在任务确有需要时调用辅助技能；
3. 原始文件无法可靠读取时，再考虑“多模态输入适配（可选）”；
4. 涉及第三方云处理前，必须执行“外部处理风险门控”；
5. 人工审核时先读对应技能的《详细说明与工作流程》；Agent 运行时先读《技能定义》，再按需读取业务模块、核心规则和检查清单；
6. 重要任务形成初步结论后，执行《统一对抗性审查规范》及对应技能的《对抗性审查清单》；
7. 检查《人工决策与升级矩阵》，确认哪些事项必须由律师复核或用户明确授权；
8. 需要正式文件时，同时使用“法律文书质量与格式控制”和相应交付规范；
9. 复杂、多文件、多轮或需要继续的事项，结束时生成《项目执行说明书》。

## 三、共同纪律

- 只基于当前可访问的任务上下文和材料工作；
- “收到材料”不等于“已经审阅”；
- 未核验事实不得写成已核验事实；
- 具体法律规则、法定时限和现行规范在任务运行时核验；
- Office、PDF、OCR、音视频等文件能力优先使用当前 Agent 或用户已有能力；
- 第三方云处理必须先告知风险并取得用户明确授权。

## 四、机器接口

为了跨 Agent 稳定运行，`skill_id`、JSON Schema 字段、枚举值和代码接口保持英文。其余面向人工阅读的内容以中文呈现。
