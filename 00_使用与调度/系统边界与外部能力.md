# 系统使用边界

## 一、任务范围

爽律 Skill 负责根据当前任务执行律师专业工作流，包括结构化材料审阅、事实建模、法律研究、证据分析、法律推理、策略比较、合同审查、争议解决、法律意见、尽职调查和文书质量控制等。

## 二、上下文使用

爽律 Skill 只基于当前 Agent 可以访问的材料、用户提供的文件和当前任务上下文工作。

如果需要继续此前事项，应提供此前的项目执行说明书、相关文件或当前工作区可以访问的已有材料。

## 三、外部工具

当任务需要文件读取、OCR、音视频转录、Office 文件生成等能力时，优先使用当前 Agent 已有能力。

如必须调用第三方服务处理客户资料、案件材料或其他敏感数据，应先告知用户并取得明确授权。

## 四、最终决策

爽律 Skill 可以形成分析、方案和建议，但涉及重大权利处分、诉讼策略、认罪认罚、和解、合同签署、对外提交等事项时，最终决定应由律师或用户作出。


## 五、外部能力不是固定依赖

爽律 Skill 不要求特定数据库、知识库、模型、OCR 或 Office 工具。运行环境提供什么能力，先按 `01_运行规范/运行能力契约.md` 登记和验证；具体调用按《外部能力适配规范》执行。

当用户明确要求使用其私有知识库或指定信源而当前环境不能访问时，不得用模型记忆或普通 Web 静默替代后声称已经满足用户要求。
