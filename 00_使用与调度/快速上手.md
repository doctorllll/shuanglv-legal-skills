# 爽律 Skill｜律师专业工作流系统——快速上手

> **公开共创版提示：** 真实案件或客户材料应先评估敏感性并做必要脱敏；重要结论和正式文件必须由律师复核。

## 你只需要记住一句话

> **“调用爽律来做。”**

然后把你的任务和材料告诉 Agent。

## 你不需要做的事情

- 不需要知道爽律 Skill 有几个内部技能；
- 不需要自己判断应该调用刑事、研究还是文书技能；
- 不需要自己选择是否调用对抗性审查；
- 不需要自己知道什么时候该调用输入适配。

这些由爽律 Skill 内部路由完成。

## 你最好告诉爽律 Skill 什么

信息越明确，工作越稳定：

- 你想解决什么问题；
- 你代表谁；
- 当前处于什么阶段；
- 已经有哪些材料；
- 哪些材料还没有；
- 最终希望得到什么成果；
- 有没有时间、格式、保密或使用场景限制。

不知道也可以不填，爽律 Skill 会根据现有输入工作，并把关键未知项标出来。

## 三个最简单的调用例子

> “调用爽律审查这份合同，代表甲方，我希望最后给我修订稿和风险说明。”

> “调用爽律分析这个刑事案件。我上传的是现有全部卷宗，先做阅卷和证据结构分析，不急着写辩护词。”

> “调用爽律研究这个问题。现行法、官方案例和反向观点都要查，不能只给我一个结论。”


## 复杂任务会多做两件事

如果任务涉及多份材料、法律研究、多条策略路径或正式交付，爽律 Skill 会尽量把中间结果继续向后传递，而不是每一步重新从长文本中猜测。新材料、新规则或对抗性审查改变原判断时，也会回写受影响的结论。

如果存在需要用户自己决定的重大策略，爽律 Skill 可以把选项、依据和主要后果整理好，但不会替用户自动作出最终决定。


## 如果你接了法律数据库或自己的知识库

不需要修改爽律 Skill 本体。告诉 Agent 当前可以访问哪些数据库、知识库或文件工具，以及你希望它使用的范围。爽律 Skill 会按外部能力契约决定何时调用、如何保留来源、何时需要降级或停止。
