# 对抗性审查清单

- [ ] 如果我是对方律师，我会怎样利用当前条款文字？
- [ ] 是否只模拟对方违约，没有模拟我方违约？
- [ ] 第三方、审批、融资、验收失败时合同怎么处理？
- [ ] 哪个定义最容易产生解释争议？
- [ ] 哪个义务没有对应权利或责任闭环？
- [ ] 哪个“很严厉”的违约责任实际上难以执行？
- [ ] 哪个条件由对方单方判断，却没有客观标准？
- [ ] 哪个履行事实将来可能无法证明？
- [ ] 文件之间是否存在定义、优先级或交叉引用冲突？
- [ ] 有没有更简单、更可执行的交易结构？
- [ ] 当前修改是否只是保护一方，却把合同改到不可谈判或不可履行？

- [ ] 如果未来发生争议，关键条款按文义、上下文、交易目的、历史版本或履行行为是否可能产生另一种合理解释？
- [ ] 是否存在义务写得很强，但履行后无法留下可证明记录？
- [ ] 付款、交付、验收、结算之间是否存在“先付后失控”或条件无法客观确认的断点？
- [ ] REVIEW/REVISE 是否只写了修改报告，却没有真正修改合同文本？
