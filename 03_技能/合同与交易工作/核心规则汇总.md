# 核心规则汇总

## 条款功能映射规则

功能：OBLIGATION / RIGHT / DISCRETION / REPRESENTATION / WARRANTY / DECLARATION / CONDITION / DEFINITION / PROCEDURE / REMEDY / RISK_ALLOCATION / LIMITATION / TERMINATION / NOTICE / DISPUTE_RESOLUTION。
每条关键条款回答：谁、做什么、何时、标准、条件、例外、对应权利、违反后果、证明方式、服务哪个风险/目标。
英文合同功能术语不自动决定中国法法律效果。

## 风险场景推演规则

对每个关键交易节点至少模拟：正常履行、对方迟延/拒绝、我方迟延/不能履行、第三方/审批失败、提前终止。
每个场景输出：trigger / affected 目标 / 影响 / controllability / current bearer / prevention / allocation / response / remedy / 证据 / clause link / 客户 决策。
无可靠数据时不得生成主观概率百分比。
