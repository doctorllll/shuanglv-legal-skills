# 被害人代理与刑事控告工作流

## 一、适用范围

本工作流适用于：
- 被害人或近亲属的刑事代理；
- 刑事控告、报案；
- 不予立案、立案后久拖未决等情形下的程序核验与救济分析；
- 立案监督相关工作；
- 刑事程序中的追赃、退赔、涉案财物和附带民事衔接；
- 进入审查起诉或审判后的被害人参与和代理。

它与辩护工作流共享事实、证据、法律研究和论证能力，但**证明目标、程序位置和策略方向独立**，不得把辩护逻辑机械反转后使用。

## 二、主流程

```text
确认委托角色与客户目标
→ 建立损害、交易和行为事实模型
→ 识别可能的刑事法律路径及民刑边界
→ 构建控告待证命题
→ 结构化审阅现有材料并建立证据包
→ 识别证据缺口、保全需求和调查路径
→ 核验管辖、受理和程序前提
→ 形成控告/报案材料与附件索引
→ 跟踪立案/受理状态并分析补充材料需求
→ 必要时进入立案监督或其他救济路径
→ 立案后转入被害人代理、追赃挽损和程序参与
→ 形成阶段交付和项目执行说明书
```

## 三、客户目标与案件目标

控告侧不能默认“立案”就是唯一目标。开始前至少确认：
- 客户主要目标是追究刑事责任、制止持续侵害、挽回损失、追赃退赔，还是保存证据；
- 是否存在民商事、行政、劳动、执行或其他并行路径；
- 是否存在紧急财产、证据灭失、人身安全或持续侵害风险；
- 客户是否有不可逆或高风险诉求，需要律师明确提示边界。

## 四、事实模型

从客户陈述和材料中重构：
- 主体、身份、关系和控制结构；
- 行为过程、交易过程或侵害过程；
- 时间、地点、金额、财物和沟通；
- 主观认识与目的的事实基础；
- 财产流向、获利、损失和结果；
- 前后行为及后续处置；
- 已有民事、行政、仲裁或其他程序；
- 已向公安、检察或其他机关提交过什么材料、收到什么文书或口头反馈。

客户陈述默认 `ALLEGED`。材料能够支持到什么程度，应逐项记录，不允许把“客户认为被骗/侵占/敲诈”等法律评价直接写成已证实的犯罪事实。

## 五、刑事路径与民刑边界

对每个拟主张罪名或刑事法律路径建立：
- 构成要件；
- 需要证明的核心事实；
- 当前支持材料；
- 反向事实和材料；
- 证据缺口；
- 与民商事争议、行政违法或一般违约的边界；
- 是否存在其他竞争性定性。

必须执行反向检查：

> 如果不成立犯罪，现有事实最可能被解释成什么？

并说明哪些事实或证据能够区分不同解释。

## 六、控告待证命题

控告材料不能只有“事情经过”。应把案件拆成可被侦查机关核查的命题，例如：
- 某主体实施了什么行为；
- 行为对象和结果是什么；
- 哪些事实支持主观方面；
- 财产或利益如何流转；
- 损失如何形成；
- 共同参与者之间如何分工；
- 哪些事实目前只有陈述，哪些已有客观材料支持。

每个重要命题连接：`FactRecord → EvidenceItem → SourceLocator`。

## 七、证据包与结构化审阅

材料较多时必须使用《通用结构化审阅规范》。控告侧至少形成：
- 材料目录；
- 时间线；
- 主体/关系表；
- 资金或财物流转表（如适用）；
- 待证命题—证据矩阵；
- 有利/不利材料；
- 矛盾和信息缺口；
- 需要机关调取而当事人难以取得的证据线索；
- 证据保全事项。

不得以“材料很多”为由把全部附件无结构地堆给办案机关。

## 八、证据保全与调查

对可能灭失、变化或被覆盖的电子数据、监控、平台记录、资金记录、物流记录、鉴定对象等，及时识别保全必要性。

律师自行调查、申请调查或建议当事人保存材料前，应检查合法性、隐私、商业秘密、个人信息和其他职业风险。

## 九、管辖、受理与提交策略

具体管辖、受理标准和程序规则必须运行时核验。分析时至少记录：
- 拟提交机关及理由；
- 犯罪行为地、结果地、主体所在地等与管辖有关的事实；
- 是否已经向其他机关提交；
- 是否存在重复、移送或程序衔接问题；
- 提交时需要的核心材料和附件索引；
- 当前尚未取得但可说明线索的材料。

控告材料应围绕可核查事实和证据组织，不用情绪化、结论先行或夸大措辞替代证明。

## 十、立案状态与监督/救济

提交后区分：
- 已接收材料；
- 是否有受案/接报案记录；
- 是否作出立案、不予立案或其他程序处理；
- 是否要求补充材料；
- 是否存在程序期限或后续救济问题。

需要立案监督或其他救济时，重新分析：
- 原提交的事实和证据是否足以支持调查必要性；
- 机关不立案或不处理的理由；
- 是否存在新的证据或法律问题；
- 当前最有效的程序路径。

不得把“没有立案”直接等同于“案件不构成犯罪”，也不得把“客户坚持”当作继续升级程序的充分理由。

## 十一、立案后的被害人代理

立案后根据程序阶段切换工作重点：
- 继续补充、核验被害人侧事实和证据；
- 关注程序性权利和信息获取；
- 对定性、证据、损失、涉案财物和追赃退赔形成意见；
- 对可能影响被害人利益的程序决定进行分析；
- 审查起诉和审判阶段准备代理意见、质证或财产主张；
- 需要时与附带民事、另行民事或执行路径协调。

## 十二、追赃挽损与财产路径

财产问题独立建模。至少记录：
- 损失项目和计算基础；
- 涉案财物流向；
- 已查封、扣押、冻结或控制的财产；
- 第三方权利；
- 追缴、退赔、返还、附带民事或其他路径；
- 事实和法律依据状态；
- 仍需核验或调查的财产线索。

## 十三、对抗性审查

正式提交重要控告材料前，至少反向检查：
- 该事项最强的“民事纠纷/行政违法/证据不足/主体不符”解释是什么；
- 是否把推断写成事实；
- 是否只有客户单方陈述；
- 关键主观要件是否只有结果倒推；
- 损失、资金流、主体身份是否有客观来源；
- 是否存在明显矛盾或对客户不利材料未处理；
- 是否为了追求立案而扩大或错误解释罪名；
- 当前还缺什么材料才能让机关有效核查。

## 十四、主要产出

- 客户目标与程序路线图；
- 事实时间线和主体关系；
- 通用结构化审阅表；
- 控告待证命题—证据矩阵；
- 民刑边界与竞争定性分析；
- 证据缺口与保全计划；
- 控告/报案材料及附件目录；
- 立案状态与补充材料清单；
- 立案监督/救济分析；
- 被害人阶段代理意见；
- 追赃挽损与涉案财物分析；
- 项目执行说明书。
