# 检查清单汇总

## 会见检查清单

## 0. 输入门控
Role / 阶段 / Urgent 期限 / Known offense / 当前-law pack / Prior meeting / File 审阅 状态。

## 1. 信息状态
- **无卷宗：** 会见目的为获取 ALLEGED 事实 + 程序事实 + 权利风险 + 证据线索；不得最终定性/刑期预测。
- **已有卷宗：** 对照卷宗核实差异、遗漏、证据解释和策略选择。

## 2. 提问顺序
1. 先自由陈述；
2. 程序/强制措施；
3. 指控核心行为；
4. 主观认识/目的（问事实，不直接问法律结论）；
5. 人员/时间/地点/资金/通信/物品；
6. 提审与笔录形成；
7. 有利/不利证据线索；
8. 陈述变化及原因；
9. 当前需求和重大决策。

## 3. 事实 状态
- 新信息：`ALLEGED`
- 独立核验：`VERIFIED`
- 与卷宗冲突：`DISPUTED`

## 4. 预测门控
信息不完整时只允许条件性法律解释、风险范围和补证事项；禁止结果承诺或精确刑期。

## 5. 风险门控
涉及传递案件信息/物品、隐匿证据、串供、秘密/隐私、诱导虚假陈述时，触发 人工复核 / 人工升级。

## 6. 输出
MeetingRecord / 事实记录（FactRecord）[] / Contradiction[] / EvidenceLead[] / Procedural问题/争点[] / 现行法 Questions[] / Follow-up Tasks。

## 证据分析检查清单

## 1. Proof 对象
先分：定罪 / 量刑 / 涉案财物 / 程序 / 证据合法或真实性事实。

## 2. 单项证据 Validator
来源 / 来源定位 / Authenticity / Collection Legality / Relevance / Reliability / Completeness / Chain / Proposition / Contradictions。
**不合并成总分。**

## 3. Confirmation + Falsification
每个关键命题必须记录：confirming 证据 / falsifying 证据 / missing expected 证据 / 备选 hypothesis。

## 4. Corroboration
声称“相互印证”前检查：
- 来源独立性；
- 是否同源转述；
- 形成时间；
- 先验知情/诱导；
- 关键一致点；
- 关键冲突点。

## 5. Statement Validator
供述/证言检查：形成条件、自愿性/合法性、前后变化、大段逐字重复异常、横纵比较、客观印证、提及但未调查线索。

## 6. Indirect 证据
`evidence → atomic fact → intermediate inference → intermediate fact → ... → ultimate proposition`
每一箭头都问：为什么成立？有无现实替代解释？

## 7. Reasonable Doubt
必须基于 证据 / logic / experience，并产生现实的无罪或罪轻可能性。

## 8. 输出
Proof Proposition 图 / 证据 矩阵 / Contradiction 矩阵 / Inference Chain / 应出现但缺失的证据 / Alternative Hypothesis / 证据 分析结果。

## 阅卷检查清单

## A. Completeness（完整性）
- 全卷或完整目录；
- 缺卷/缺页/不可读记录；
- 卷号—材料—页码索引；
- 与前一阶段版本做 Diff；
- 所有缺失形成 来源缺口。
**禁止：** 因预设辩点选择性不复制。

## B. First Pass（控方地图）
起诉意见/起诉书 → 指控事实 → 罪名/要件 → 控方命题 → 关键证据 → 程序来源。

## C. Second Pass（全面证据）
每项进入 证据对象（EvidenceItem）：来源 / locator / proposition / authenticity / legality / relevance / reliability / 完整ness。

## D. Focus Pass（辩护假设）
每个假设必须有：支持材料 / 反向材料 / 证据缺口 / 备选 explanation / current-law issue。

## E. Comparison（比对）
按需建立：
- 同一人口供纵向表；
- 同案人员横向表；
- 时间线；
- 金额/资金流；
- 通信/位置；
- 证据发现时间链。

## F. 会见回路
卷宗与会见不一致 → 回会见核实；新会见信息 → 回卷宗/调查/研究核实。

## G. 停止条件
只有全卷状态、控方证明链、支持/反向证据、关键矛盾/缺口、现行法 问题/争点 均显式，才允许进入较稳定 Defense 分析结果。

## 被害人代理与刑事控告检查清单

- [ ] 已分析至少一种非犯罪或替代事实解释
- [ ] 拟主张刑事路径的构成要件和现行规则已核验或标记待核验
- [ ] 已建立控告待证命题—证据矩阵
- [ ] 多文件材料已按通用结构化审阅规范整理
- [ ] 关键主观事实不是仅由结果倒推
- [ ] 已识别证据缺口和需要机关调取的线索
- [ ] 已检查证据保全和调查合法性风险
- [ ] 管辖、受理和程序路径已核验或明确待核验
- [ ] 控告/报案材料包含可核查事实、来源定位和附件索引
- [ ] 已记录受理/立案/不立案/补充材料等真实程序状态
- [ ] 需要监督或救济时已重新分析证据与程序基础
- [ ] 追赃、退赔、返还、附带民事或其他财产路径已单独分析
- [ ] 正式提交前已执行对抗性审查和人工决策检查
