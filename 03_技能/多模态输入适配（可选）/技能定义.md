# 多模态输入适配（可选）

`skill_id: multimodal-input-adapter`

**系统版本：0.40**

> **人工核验提示：** 如果你要先理解本技能的完整方法和工作流程，请先阅读同目录《详细说明与工作流程.md》。本文件主要用于 Agent 执行。

**Type：OPTIONAL INFRASTRUCTURE SKILL（可选基础设施技能）**

## 用途（目的）

当当前 Agent 或用户已有 技能 无法可靠读取输入格式，或无法满足法律工作所需的 来源定位 / OCR / Timestamp / Table Structure 质量要求时，为文件提供**格式转换与标准化输入**。

> 本技能 解决“文件怎么变成可可靠读取的输入”，不负责法律内容分析。

## 适用场景（触发）

仅在以下情况触发：
1. 当前 Agent 不支持该格式；
2. 当前 Agent能读，但无法满足 `input-quality-specification（输入质量规范）`；
3. 用户明确要求使用该 技能；
4. 用户希望使用指定 OCR / ASR / 视频 / 文书 Parser。

## Do Not 适用场景（不触发）

- 当前 Agent 的原生能力已经满足输入质量；
- 用户已有更合适的 OCR / 音频 / 视频 / PDF 技能；
- 任务只涉及纯文本且无需转换；
- 外部处理未获用户授权。

## Routing Priority（路由优先级）

```text
1. Native Agent Capability
2. User-provided 技能 / Plugin
3. Local / Offline Adapter
4. User-controlled Infrastructure
5. Third-party Cloud Adapter
```

## 服务商 / Tool Examples（非绑定）

可以适配：
- 当前Agent原生多模态能力；
- 用户已有 PDF/OCR/音频/视频 技能；
- 本地 PaddleOCR 等 OCR；
- 本地/用户自管语音转录；
- 用户选择的云OCR/语音/视觉服务；
- 阿里云等第三方云服务。

**供应商具体产品名、API、Endpoint、价格、留存政策可能变化；真正配置时必须查阅供应商当前官方文档，不在技能内静态写死。**

## 执行交接（执行交接）

本技能 **不承担长期记忆或项目数据库**。

当任务属于多文件、案件/项目、多轮继续、跨 技能、正式交付或存在未解决事项时，执行结束必须按照：

`00_使用与调度/项目执行说明书规范.md`

形成 `项目执行说明书（项目执行说明书）`，至少记录：

- 收到了哪些材料；
- 实际审阅了哪些材料、范围是什么；
- 哪些材料只收到但未审阅；
- 本次做了哪些工作；
- 当前形成了哪些 分析结果 / 缺口；
- 产出了哪些文件/版本；
- 哪些问题仍未解决；
- 下一步建议调用哪个 技能、需要什么输入。

简单一次性任务可以不单独生成完整说明书，但不得因此混淆“收到 / 已读 / 已完成”的状态。


## 与运行能力档案的关系

本技能只在当前 Agent 原生能力或用户已有工具不能满足输入质量时触发。OCR、视觉、音视频和文件提取能力应先进入运行能力档案，并按 `01_运行规范/文件与多模态能力契约.md` 选择；第三方云服务仍受外部处理风险门控。
