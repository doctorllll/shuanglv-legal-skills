# 对抗性审查清单

- [ ] 当前 Agent 原生能力是否其实已经足够，是否属于不必要外部处理？
- [ ] 用户是否已有更合适的本地或自有工具？
- [ ] 是否为了方便而发送了超出必要范围的文件？
- [ ] 第三方云服务是否已经取得本次明确授权？
- [ ] API Key 是否被错误当成上传授权？
- [ ] 本地处理失败后是否发生了静默切云？
- [ ] OCR/转录是否保留页码、时间戳或其他定位？
- [ ] 模糊字符、听不清内容是否被自动猜测补全？
- [ ] 表格结构是否在转换中丢失？
- [ ] 识别结果是否被错误提升成“已核验事实”？
- [ ] 重要识别结果是否需要人工回看原始文件？
