# 多模态输入适配（可选）——详细说明与工作流程

`skill_id: multimodal-input-adapter`

## 一、为什么需要这个技能

它只解决一个问题：**当前 Agent 自己读不了某种文件，或者虽然能读但达不到法律工作所需的页码、时间戳、表格结构等质量时，如何把原始文件转换成可靠的标准化输入。**

它不负责法律分析。如果当前 Agent 原生已经能可靠读取，就不调用。

## 二、调用优先顺序

```text
当前 Agent 原生能力
→ 用户已经拥有的文件处理技能
→ 本地离线工具
→ 用户自己控制的服务器或接口
→ 第三方云服务
```

原则是能在当前可信环境解决，就不额外把材料发送出去。


## 三、执行步骤速查表

| 步骤 | 要做什么 | 主要方法 | 阶段产物 |
|---|---|---|---|
| 1. 能力判断 | 确认当前Agent是否真的读不了或质量不足 | 任务所需质量对比运行能力 | 是否需要适配 |
| 2. 现有工具优先 | 检查用户已有工具 | 原生→用户工具→本地→外部的优先级 | 处理路线 |
| 3. 敏感性判断 | 判断材料是否适合外发 | 客户秘密、个人信息、案件材料分级 | 风险等级 |
| 4. 外部授权 | 第三方云调用前取得同意 | 服务商、数据范围、用途、费用、留存风险告知 | 授权记录 |
| 5. 凭证处理 | 安全使用API凭证 | 环境变量/Secret Store，禁止写入项目文件 | 凭证引用 |
| 6. 转换 | OCR、音频转录、视频/图像识别 | 根据文件类型选择适配器 | 转换结果 |
| 7. 定位保留 | 让结果可以回到原始文件 | 页码、时间戳、工作表、图像区域 | 来源定位 |
| 8. 不确定性标记 | 不猜模糊内容 | OCR/转录状态、不可读区域显式标记 | 质量标记 |
| 9. 输入QA | 检查转换是否达到法律任务要求 | 完整性、定位、表格结构、错误检查 | 标准化输入 |
| 10. 交接 | 将可读结果交业务技能 | 内容与来源定位一起传递 | 标准化输入清单 |

## 四、主流程

```text
识别文件类型和任务所需质量
→ 检查当前 Agent 是否已经满足
→ 检查用户是否已有合适工具
→ 选择本地或外部处理方案
→ 判断材料敏感程度
→ 如需第三方云，先告知风险并取得明确授权
→ 安全使用凭证
→ OCR/转录/图像或视频识别
→ 保留页码、时间戳、工作表、区域等来源定位
→ 标记不确定性和不可读区域
→ 做输入质量检查
→ 输出标准化输入清单
→ 交给法律业务技能
```

## 五、真正判断的是“质量够不够”

“模型能打开 PDF”不等于可以用于法律工作。能读全文但没有页码、OCR 把金额识别错、表格被打散、音频没有时间戳、视频只有概括没有关键时间点，都只能算部分可用。

如果任务需要精确引用，必须保留足够的来源定位。

## 六、来源定位要求

转换后尽量保留：PDF 文件名+页码；Word 文件名+标题/段落；Excel 文件名+工作表+单元格/范围；图片文件名+区域；音频文件名+时间戳；视频文件名+时间戳+关键帧；压缩包路径+内部文件路径。

最差的做法是把数百页卷宗 OCR 成一大坨纯文本，页码全部丢失。

## 七、OCR 和转录不确定性

识别结果要区分原生文本、OCR、音频转录、部分识别和无法确认。模糊字符、听不清内容、画面不明处不得自动补全，要标记不确定区域，重要信息要求人工回看原始文件。

转换结果只是“读取结果”，不自动成为法律上的已核验事实。

## 八、第三方外部处理风险门控

准备把材料发送第三方云之前，必须告知服务商、发送哪些文件/片段、用途、可能涉及的客户秘密/个人信息/案件材料/商业秘密、日志和留存取决于供应商政策、可能费用、识别错误以及本地替代方案。

用户必须明确授权本次处理。已经配置 API Key 不等于已经授权上传当前案件文件。

## 九、禁止静默切云

用户选择本地处理而本地工具失败时，应报告失败并提供选择；不得为了完成任务自动把文件上传云端。任何从本地切换为外部处理，都要重新经过风险告知和授权。

## 十、凭证安全

可以指导注册服务、创建最小权限凭证、写入环境变量或 Secret Store 并测试连接，但不能把 API Secret 写进技能包、项目说明书、普通 Markdown、案件文件或可长期回显的正文。

## 十一、主要产出

标准化输入清单、OCR 文本、音频转录、视频时间戳和关键帧、表格结构、来源定位、识别方式、处理服务商、质量状态、不可读/不确定区域和必要警告。

业务技能拿到这些结果以后才开始事实、证据和法律分析。

## 十二、人工核验路径

依次看《详细说明与工作流程》《技能定义》《核心规则汇总》《检查清单汇总》《适配器说明》《输入质量规范》《外部处理风险门控》。核心不是“内置多少 OCR 模型”，而是：**什么时候需要转换、如何保证来源定位、什么时候必须获得用户授权**。

## 正式交付前：统一对抗性审查

对于重要任务，本技能形成初步分析后不能直接交付。应再执行同目录《对抗性审查清单》，并结合系统级《统一对抗性审查规范》主动寻找反向事实、反向证据、替代解释、规则例外、结论翻转点和仍未解决的缺口。

对抗审查发现的问题应反馈到正文、策略、研究或风险判断中，而不是仅在末尾写一句“已复核”。如涉及重大策略或权利处分，再按《人工决策与升级矩阵》转律师复核或等待用户明确授权。
