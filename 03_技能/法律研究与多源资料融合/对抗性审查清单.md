# 对抗性审查清单

- [ ] 是否只搜索了支持当前观点的来源？
- [ ] 是否主动检索了反向案例、例外、分歧和边界？
- [ ] 是否存在更高位阶、更当前或更原始的法律来源？
- [ ] 是否把“数据库/官网/公众号/网页”本身误当作来源权威等级？
- [ ] 是否漏掉法院、检察机关等官方公众号/网页上的高质量原创解释、白皮书、典型案例或实践信号？
- [ ] 是否把高权威解释性材料误写成正式法律规范？
- [ ] 是否把专业文章的观点误写成已证实事实？
- [ ] 是否把二次转载或摘要误当原始来源？
- [ ] 检索词是否过窄，导致确认偏误？
- [ ] Research Ladder 是否在当前层已经失效却仍重复搜索？
- [ ] 类案是否只是关键词相似，而决定性事实其实不同？
- [ ] 是否检查案例的法律版本、程序阶段和证据结构？
- [ ] “没有搜到”是否被错误写成“没有”？
- [ ] 是否因为已经搜到很多材料而过早宣称 SATURATED？
- [ ] 哪个来源缺口一旦补齐可能改变结论？
- [ ] 正式研究交付是否选对了 Deliverable Profile？
- [ ] 用户已有研究报告模板/习惯是否被系统默认格式覆盖？
- [ ] 修正后的研究结论是否明确限制和不确定性？
