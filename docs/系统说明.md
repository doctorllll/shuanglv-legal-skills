# 爽律 Skill v0.48｜系统说明

## 定位

**可被 Agent 按需发现和加载的中国律师专业 Operating Protocol。**

Runtime 采用 Thin `SKILL.md` + On-demand Shared Capabilities + Domain Extensions + Conditional Guards + Minimal Matter State + Loose Interop。

`SKILL.md` 分成两层：

1. **YAML frontmatter（Discovery Layer）**：提供 `name / description` 等最小发现信息，让支持 Agent Skills 的 Host 判断什么时候应加载爽律；
2. **Markdown body（L0 Runtime）**：只保留入口级专业完整性、任务框架、按需加载映射和关键执行控制，厚方法继续放在 `references/` 中按需加载。

Shared Capabilities：Facts / Evidence / Research / Reasoning / Strategy / Composition / Review。

Domains：Criminal（THICK）/ Contract（THICK）/ Civil（MEDIUM-THICK）/ Due Diligence（MEDIUM-THICK）/ Advisory（THIN）。v0.48 不扩建行政诉讼、企业合规或长期法律顾问领域。

v0.48 继续保持按需加载与 Runtime 精简机制，并重点收口正式对外交付边界、法律信源互操作以及研究与文书质量验证。用户实际使用方式请优先阅读 `User_Guide/`；第一次进入项目可直接阅读根目录 `README.md`。

Runtime 不包含法律数据库、OCR/Office/PDF 引擎、通用项目管理系统或持久 Memory Engine。Host 能力不足时必须真实降级，不得虚构读取、检索、提交、签署、修订或持久化已经发生。

## 能力保真

Runtime 精简只允许减少重复和常驻上下文，不允许删除旧版本已经存在且仍应保留的有效能力。Agent Skills discovery metadata 属于入口能力的一部分，后续版本必须纳入 Capability Preservation Regression。
