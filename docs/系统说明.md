# 爽律skill v0.50｜系统说明

## 定位

**可被 Agent 按需发现和加载的中国律师专业工作流系统。**

正式运行层采用“轻量入口 + 按需共享能力 + 业务领域扩展 + 条件风险控制 + 最小事项状态 + 松耦合外部能力”的结构。

`SKILL.md` 负责发现、任务框架、按需加载映射和关键执行控制；具体专业方法放在 `references/` 中按需加载。

当前共享专业能力包括：事实、证据、法律研究、法律论证、策略、成文、复核、法律可视化。

当前主要业务领域包括：刑事案件办理、民商事争议解决、合同与交易工作、尽职调查与专项调查、法律顾问与专项法律分析。

当前系统遵循“小任务小流程、大任务按需要加深”的运行原则，并支持事项连续性、批处理、核验台账、外部能力适配、专业成果真实性控制和法律可视化等跨业务共享机制。

Runtime 不包含法律数据库、OCR/Office/PDF 引擎、通用项目管理系统或持久 长期记忆引擎。Host 能力不足时必须真实降级，不得虚构读取、检索、提交、签署、修订、渲染或持久化已经发生。
