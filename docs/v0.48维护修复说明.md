# v0.48 维护修复说明｜README 产品首页与 Skill Discovery

> 本文记录 v0.48 正式发布后发现并修正的两个交付遗漏。版本号保持 v0.48，不扩展新的法律业务 Domain。

## 一、为什么需要修复

### 1. 根 README 从“产品首页”退化成了“文档导航页”

v0.41 / v0.43 的根 README 原本直接承担产品首页职责，包含“这是什么、包含哪些能力、怎样工作、怎么使用、边界在哪里”等核心内容。v0.48 在建立独立 User Guide Layer 时，错误地把大部分用户可见说明下沉到 `docs/User_Guide/`，根 README 只剩约 30 行导航内容。

问题不在于说明材料完全不存在，而在于**信息架构归位错误**：第一次进入 GitHub 或解压成果包的人，不能只看首页就理解爽律。

本次修复重新把首页应承担的内容放回根 README，同时继续保留 User Guide 作为详细说明层，Runtime 仍只负责行为规则。

### 2. PR #1 指出的 Agent Skills Discovery 能力发生回退

2026-08-15，GitHub 用户 `doctorllll` 提交 PR #1，指出 `SKILL.md` 如果缺少 YAML frontmatter，支持 Agent Skills discovery 的宿主可能无法正常发现和触发爽律。该 PR 仅针对入口元数据，并未修改法律业务规则。

v0.43 主线随后已经实现更完整的 `name / description / license / compatibility / metadata`，因此 PR #1 因“上游已实现”而关闭。当前 v0.48 检查发现：后续精简重构后，`runtime/shuanglv-legal-skills/SKILL.md` 又重新从 Markdown H1 开始，frontmatter 消失。

该问题定性为：**Capability Preservation Regression**。本次按 v0.48 当前架构恢复，而不是照抄旧 PR 或旧版本。

## 二、本次实际修改

### README

重新整合：

- v0.41 / v0.43 中成熟的“产品首页”职责；
- v0.48 当前真实能力地图；
- Thin Runtime / 按需加载架构；
- Facts / Evidence / Research / Reasoning / Strategy / Composition / Review；
- Internal Analysis → External Deliverable Boundary；
- Jurisdiction Stack Closure；
- Host capability truth / graceful degradation；

- 用户偏好和模板与 Core 分离；
- Agent Skills Discovery 与显式调用；
- 当前能力边界、安装入口和详细 User Guide 导航。

README 不复制 Runtime 全文，也不把 Advisory、行政诉讼、企业合规、长期法律顾问等未扩建能力包装成现有功能。

### SKILL.md

在现有 v0.48 Markdown body 之前恢复 YAML frontmatter：

- `name: shuanglv-legal-skills`；
- `description`：按 v0.48 当前真实业务范围和触发/反触发语义重写；
- `license`：指向当前 ShuangLaw Professional Use License 1.0；
- `compatibility`：说明 Agent Skills Host 与外部工具能力边界；
- `metadata`：作者、语言、显示名称、主页和 system id。

现有 v0.48 Runtime body 不重写，不新建 Runtime 文件。

### 安装说明 / 系统说明 / 致谢

## 四、防复发门

后续正式发布必须新增两组硬检查：

### README_PRODUCT_HOME_GATE

- 根 README 必须直接解释“是什么 / 当前能力 / 怎样工作 / 怎么使用 / 使用边界”；
- 不能只把用户导流到 `docs/User_Guide/`；
- README 与 Skill 能力地图、版本号和 Runtime 边界必须一致；
- 上一正式版已有的重要用户可见说明不得无 ADR 地被删除。

### SKILL_DISCOVERY_PRESERVATION_GATE

- `SKILL.md` 第一非空内容必须为 YAML frontmatter；
- YAML 必须可解析；
- `name` 必须为 `shuanglv-legal-skills` 且与父目录一致；
- `description` 必须非空并满足 Agent Skills 约束；
- frontmatter 后仍必须保留 v0.48 L0 body；
- README 声称支持 discovery 时，SKILL.md 必须实际具备有效 metadata；
- 任一失败：Release Gate = FAIL。
