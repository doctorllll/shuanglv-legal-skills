# 爽律skill v0.50｜安装、调用与自动更新说明

## 一、安装成功的最低条件

1. 宿主 能读取 `runtime/shuanglv-legal-skills/SKILL.md`；
2. `SKILL.md` 能按需访问同目录 `references/`；
3. 宿主 自身提供实际可用的 Web、法律数据库、OCR、Office/PDF、文件读写等能力；爽律skill只规定专业需求、质量边界和授权边界；
4. `docs/` 是用户说明层，不应作为 正式运行层常驻指令加载。

## 二、调用

在支持 Agent Skills 自动发现的 宿主 中，通常直接描述法律任务即可。也兼容显式调用，例如：

```text
调用爽律skill，帮我分析这组刑事卷宗。
```

如果 宿主 要求 `SKILL.md` 位于 Skill 根目录，可直接把 `runtime/shuanglv-legal-skills/` 作为安装目录。

## 三、自动更新到最新正式版

把仓库链接发给具备联网和文件写入权限的 Agent：

```text
https://github.com/zj-ai-lab/shuanglv-legal-skills
```

然后直接说：

```text
帮我把这个爽律skill更新到最新正式版。
```

Agent 应核对当前版本、获取最新正式版、保留用户自己的模板/偏好/事项资产、替换正式运行层和同版本用户文档，并完成基本完整性检查。若当前宿主 没有相应权限，应明确说明，不能假装已经更新。

## 四、正式包内的操作手册

完整操作说明见：

`docs/User_Guide/爽律skill_v0.50_全模块操作手册.html`

该 HTML 为正式成果包固定用户文档，解压后可直接用浏览器打开。
