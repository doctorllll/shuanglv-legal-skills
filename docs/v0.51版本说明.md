# 爽律skill v0.51｜版本说明

**版本状态：正式版**  
**继承基线：v0.50 正式版**

v0.51 是可靠性升级，不以新增更多法律业务模块为主。

## 本版两项基础可靠性升级

### 1. 更新安全与用户资产保护

- 新增根目录 `UPDATE_INSTRUCTIONS.md`；
- 明确官方程序层 / 用户资产 / UNKNOWN 三类边界；
- UNKNOWN 默认保护；
- 更新前必须盘点并保护用户资产，禁止未经检查默认整目录删除；
- 更新后同时验证程序层与用户模板、偏好/配置、Matter/Resume、用户文件。

### 2. 执行控制与可见核验

- 新增 `TaskExecutionContract`、`ModuleExecutionLedger` 与模块级完成依据；
- 区分实体文件状态与专业成果生命周期；
- 上游变化会定向使受影响下游结果失效/重审；
- 用户实质否定此前完成判断时触发状态重置；
- 深度研究增加充分性门，重大正式交付增加完成性审查；
- 长任务阶段汇报后默认继续执行，只有真实人工干预节点才暂停；
- 最终重大交付提供简洁“爽律skill执行核验”。

## 保持不变

五大业务域、八项共享专业能力、v0.50 法律可视化能力、用户模板优先级、现行法/来源/敏感材料/人工决定等硬边界继续保留。
