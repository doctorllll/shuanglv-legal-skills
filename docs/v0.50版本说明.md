# 爽律skill v0.50｜版本说明

**版本主题：法律可视化能力升级**  
**发布日期：2026-08-19**

## 本版重点

v0.50 在既有事实、证据、法律研究、论证、策略、成文、复核能力之上，新增法律可视化共享能力。系统先判断是否值得画，再根据时间、关系、资金、流程、证据、要件、争点、论证和方案等结构选择合适表达。

## 主要新增

- 新增法律可视化共享能力；
- 静态成果作为可靠基础，交互确有增益且 宿主 支持时可进入动态版本；
- 静态、交互与快照共享同一法律语义与数据基础；
- 图形继续受事实状态、来源、证据和正式交付规则约束；
- 防止把推断画成事实、改变金额/日期/关系方向、隐藏反向信息或制造虚假独立印证；
- 正式成果包内置同版本 HTML《全模块操作手册》。

## 继承能力

本版继续保留此前已经形成的：小任务小流程、复杂事项按需加深、事项连续性、批处理、核验台账、供应商中立外部能力、专业成果与实体文件分离、重大人工决定与外部动作授权边界。
