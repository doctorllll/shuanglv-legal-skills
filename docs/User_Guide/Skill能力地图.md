# 爽律skill 能力地图

> 只列出 v0.50 当前已经存在的能力。能力名称是面向律师用户的归纳。

## 一、刑事方向｜criminal-casework（刑事案件办理）

- 案件角色、阶段与任务识别；
- 材料目录、事实结构、时间线和矛盾点整理；
- 会见、阅卷和案件建模辅助；
- 单项证据与全案证明体系分析；
- 罪名、构成要件及刑法问题分析；
- 强制措施、审查起诉、审判等阶段策略辅助；
- 被害人代理、刑事控告等现有刑事工作路径；
- 辩护意见、阶段法律意见等文书辅助；
- 需要时联合法律研究、证据、策略、写作与复核能力。

## 二、民商事方向｜civil-commercial-dispute-resolution（民商事争议解决）

- 客户目标与争议路径识别；
- 材料、事实、时间线、主体关系与履行流程整理；
- 请求权基础、请求与抗辩结构分析；
- 要件—主张—争点矩阵；
- 证据与举证责任分析；
- 管辖、时效/期间、保全、仲裁、反诉等程序问题辅助；
- 诉讼/仲裁策略、和解窗口与执行可行性分析；
- 起诉状、答辩状、代理意见等诉讼文书辅助；
- 庭前和庭审准备辅助。

## 三、合同与交易方向｜contract-and-transaction-work（合同与交易工作）

- 交易目标、代表方和合同工作模式识别；
- 交易结构与文件架构分析；
- 履行流程、权利义务和依赖关系梳理；
- 双向风险场景推演；
- 合同起草、审查、修改和实际落稿；
- 条款功能、覆盖、可操作性和可证明性检查；
- 谈判立场、让步与交换条件辅助；
- 签署、交割、履行与证据留存交接提示；
- 清洁稿、差异稿、修改说明等交付辅助（具体文件能力取决于宿主）。

## 四、尽调与专项调查｜due-diligence-and-investigation（尽职调查与专项调查）

- 尽调目的、范围、排除项和重要性确定；
- 动态资料清单与数据室完整性管理；
- 材料来源、版本、完整性和可读性记录；
- 公开查询、访谈、现场或第三方资料的多源核验方法；
- 事实核验与 Expected-but-Missing 缺口识别；
- Red Flag、风险影响和补救措施整理；
- 风险向合同、交易条件或行动方案的交接；
- 尽调报告和有明确边界的专项事实调查辅助。

## 五、法律顾问与专项分析｜legal-advisory（法律顾问与专项法律分析）

- 把表面提问重构为真实决策问题；
- 区分已知事实、陈述、争议、未知和经授权假设；
- 建立问题树并组织法律研究；
- 法律结论、风险/机会、方案和律师建议分层；
- 多方案比较与行动计划；
- 快速咨询、内部备忘、专项分析、正式法律意见内容基础。

**边界：** 当前 Advisory 仍为薄层，不等同于完整的长期法律顾问运营系统、CRM 或持续管理报告平台。

## 六、通用法律研究｜legal-research-and-source-fusion（法律研究与多源资料融合）

- 法律问题、法域和时间范围界定；
- 权威来源层级与 SourceRole 区分；
- 现行法、修法和时间效力核验；
- 递进式检索与原始来源追溯；
- 类案的决定性事实、裁判理由、相同点和区别点比较；
- 支持、反向、边界、区别和例外案例检索；
- 重大裁判/观点分歧识别；
- 检索充分性和结论支持范围控制。

## 七、通用文书质量｜legal-document-quality-control（法律文书质量与格式控制）

- 明确作者、读者、文书目的和交付模式；
- 事实状态、法律引用、证据定位和附件一致性检查；
- 论点排序、论证结构、展开尺度和读者适配；
- 减少 AI 问答式、同构式和模板化表达；
- 清洁稿、差异稿、批注/修订要求和版本管理；
- FORMAT_ONLY 模式下保持实体内容不变；
- 正式交付前的语义校对、机械校对和对抗性复核；
- 内部分析 → 对外交付边界与 正式交付检查。

## 八、跨领域共享能力

除以上主要 Skill 外，爽律skill按任务需要组合以下共享能力：

- **事实整理**：材料目录、事实状态、时间线、冲突与缺口；
- **证据分析**：事实—证据映射、真实性/合法性/关联性/可靠性、独立性与证明充分性；
- **法律论证**：规则—事实—证据—分析—结论及竞争解释；
- **策略分析**：选项、风险/取舍、顺序、时点和需要人工决定的节点；
- **对抗性复核**：最强反方、翻转点、缺陷与回写修正；
- **法律可视化**：时间、关系、资金、流程、证据、要件、争点和论证结构的静态/交互表达；
- **材料输入适配**：PDF/OCR、表格、图片、音视频等，取决于当前宿主 的真实能力。

## 九、当前能力边界

- 当前没有独立的行政诉讼业务模块；
- 当前没有独立的企业合规业务模块；
- 法律顾问能力以有明确边界的专项分析为主，不等同于 CRM 或完整长期顾问运营平台；
- 法律数据库、OCR、Office、PDF、多模态和其他外部工具能力取决于实际宿主环境。


## 十、跨业务共享机制

这些不是新增业务领域，而是供现有技能按需共同使用的能力：

- **LegalWorkProfile（法律工作配置）**：复用已经确认的法域、来源、模板、敏感材料和交付偏好；
- **Matter Professional Index（事项专业索引）**：支持跨轮次续接、结果复用和依赖变化后的定向失效；
- **Batch Contract（批处理契约）**：统一大量材料的样本、批量、异常和人工复核逻辑；
- **核验台账**：统一记录重要事实、证据、法律、案例和结论的核验状态；
- **外部能力适配**：以“法规检索、案例检索、OCR、Word 修改”等能力识别工具，而不是绑定某个品牌；
- **专业成果契约**：统一高频法律成果的必要字段、来源和交付真实性要求。

这些机制继续服从“小任务小流程、大任务按需要加深”的原则。

## 十一、法律可视化共享能力

法律可视化使用已经形成的事实、证据和分析结果作为同一语义来源：先判断是否值得画，再决定图型、表达重点以及静态或交互方式。图形不建立第二套事实数据库，也不能改变原有事实状态、证据强度或来源。
