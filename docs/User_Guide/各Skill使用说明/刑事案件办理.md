# criminal-casework（刑事案件办理）

## 一、用途

用于刑事案件从接案、会见、阅卷、证据分析、罪名与法律问题、阶段策略到辩护/代理文书的专业辅助。它是刑事领域方法，不替律师作认罪、上诉、披露策略等最终决定。

## 二、适用场景

- 接案后快速梳理案件角色、阶段、期限和材料；
- 会见提纲、会见记录整理和前后陈述比对；
- 多卷宗阅卷、事实建模、时间线和人员/资金关系整理；
- 单项证据审查、证据链、同源信息、矛盾和合理怀疑分析；
- 罪名构成、违法性/责任、量刑和程序问题分析；
- 强制措施、审查起诉、审判阶段的策略辅助；
- 辩护意见、法律意见、刑事控告等文书辅助。

## 三、输入材料要求

至少说明委托角色、当前程序阶段、已掌握材料和当前任务。重要分析最好提供讯问/询问笔录、证据材料、起诉/拘留/逮捕等程序文书、关键书证电子数据及必要时间信息。缺失材料应保持未知，不要让 AI 补全。

## 四、输出结果

可生成材料目录、案件概要、时间线、事实/证据矩阵、矛盾与缺口、罪名分析、证明体系分析、阶段行动清单、辩护问题树、内部策略分析、会见/阅卷辅助成果和正式文书草稿。

## 五、推荐使用方式

大案先“建模后写作”：先审阅材料和证明体系，再研究法律和形成策略，最后才写辩护词。对关键结论要求来源定位；对重要辩点要求做最强反方审查。新增卷宗后只更新受影响结论，避免每次从头生成。

## 六、常见错误

- 只听家属或当事人口述就要求确定罪名和结论；
- 一上传卷宗就直接要求“写完整辩护词”；
- 把多份转述同一信息的材料当作独立印证；
- 只分析有利证据，不处理关键不利证据；
- 把“法律上可能”写成“本案一定”；
- 让 AI 替当事人作认罪认罚、上诉或其他保留给人的决定。

## 七、示例任务

1. “这是侦查阶段卷宗和三次会见记录。先做时间线、关键人物和证据来源图，再找同源证据、前后陈述冲突和目前无法证明的关键命题。”
2. “我们准备提交不批准逮捕法律意见。先审查社会危险性和定罪证据两个层面，再做一轮检察机关最强反方审查，最后形成对外版本。”
3. “新增一份电子数据鉴定意见。请判断它影响哪些既有证据结论和辩点，只更新受影响部分并列出需要重新核验的事项。”
