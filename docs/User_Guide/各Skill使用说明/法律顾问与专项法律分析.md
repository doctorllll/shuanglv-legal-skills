# legal-advisory（法律顾问与专项法律分析）

## 一、用途

用于日常法律咨询、专项问题分析、管理层/客户决策支持和法律意见内容组织。重点是把“问法条”转成“要作什么决定、有哪些方案、风险和行动是什么”。当前能力是专项咨询薄层，不是完整长期法律顾问运营系统。

## 二、适用场景

- 客户问“能不能做/怎么做/风险是什么”；
- 重大事项的专项法律分析；
- 多个合法方案之间的比较与建议；
- 管理层决策备忘、内部法律备忘；
- 正式法律意见书的事实、法律、方案和行动内容基础。

## 三、输入材料要求

说明客户真实目标、希望作出的决定、已知事实和材料、关键未知事项、时间要求，以及是否允许使用明确标注的工作假设。涉及现行法或专项监管问题时，应允许实际检索或提供权威来源。

## 四、输出结果

可生成重构后的决策问题、事实基础、问题树、研究任务、法律分析、风险/机会、方案比较、律师建议、需要客户决定的事项、行动计划、内部备忘或正式意见内容基础。

## 五、推荐使用方式

要求 AI 分开表达“法律结论—律师建议—客户决定”；对重大风险同时寻找合法替代路径或缓释措施；研究不足要把限制传递到最终意见。正式意见前要求对抗性复核和对外交付检查。

## 六、常见错误

- 客户先给结论，再要求 AI 找理由证明；
- 关键事实缺失却默许 AI 补假设；
- 只罗列风险，不给可执行方案；
- 用伪精确百分比描述没有统计依据的法律风险；
- 把商业选择写成“法律必须如此”；
- 把本 Skill 当作 CRM、长期顾问工单或持续项目管理系统。

## 七、示例任务

1. “客户问‘这个业务能不能上线’。请先把真正决策问题拆开，列事实缺口、适用规则、可行方案和每个方案的实施前提，不要只回答能/不能。”
2. “基于现有材料形成董事会内部法律备忘：分开法律结论、经营层可选方案和需要董事会决定的事项。”
3. “把这份内部分析转成正式法律意见书前，先检查哪些假设尚未获客户确认、哪些研究结论仍有限制。”
