# 爽律skill｜法律可视化使用说明

## 1. 不需要记调用口令

正常提出法律任务即可。例如“把资金流理清楚”“把这些证据和待证事实对应起来”“这个交易结构给客户讲清楚”“做一张庭审展示图”。当图形明显比文字更有效时，爽律skill 会按需加载法律可视化能力；简单任务不会为了好看强行画图。

## 2. 常见可视化

- 时间：普通时间线、比例时间线、期间图、泳道时间线；
- 主体与交易：关系图、层级/控制关系、交易结构；
- 金流：资金流与多跳路径；
- 流程：履行、程序、条件/分支流程；
- 证据与论证：证据图、要件—事实—证据图、争点树、论证图；
- 方案：Option Tree / 比较视图；
- 统计：只有真实数据时使用图表，不造数字。

## 3. 静态与交互

默认先保证静态版可用。复杂图如果需要搜索、筛选、来源跳转、时间滑块、路径高亮、展开/折叠或观点切换，并且当前宿主真实支持，爽律skill 可以提供动态/交互版本。动态成果也可以作为正式交付，但原则上会同时保留静态快照。

如果你一开始明确要求“动态关系图”“交互 HTML”等，不需要再次确认。

## 4. 图上的内容从哪里来

可视化不重新编一套案件事实。节点、关系、金额、日期、证据状态、争点和来源应引用爽律skill 已有的事实/证据/推理对象；重要信息保留 source / locator。

`隐藏 ≠ 删除；筛选 ≠ 否认；聚焦 ≠ 证明。`

## 5. 生成式视觉增强

如果宿主具备生图能力，背景、非语义图标、插画或视觉气氛可以作为可选增强。但人物、金额、日期、证据编号、箭头方向、法律关系和事实状态必须来自确定性层。敏感案件需要外部服务处理时，仍须遵守外部处理授权边界。

## 6. 宿主 不支持怎么办

爽律skill 会按“等价能力 → 可接受降级 → 阻断”的顺序处理。不能生成交互但静态足够时，应明确降级为静态；只能输出图形规范/图源时，不得声称已经生成 PNG/PDF/HTML 文件。
