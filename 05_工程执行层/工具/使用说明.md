# 爽律 Skill执行器使用说明

执行器为可选的本地辅助工具，仅使用 Python 标准库，不需要额外安装依赖。

## 1. 生成执行计划

```bash
python "05_工程执行层/工具/爽律 Skill执行器.py" plan   --task "审查这份合作协议，我代表甲方，需要正式修订稿"   --role "甲方律师"   --important   --formal-delivery   --need-current-law   --structured-review   --strategy-choice   --out /tmp/plan.json
```

如果自动路由不能唯一确定，可以显式指定主技能：

```bash
python "05_工程执行层/工具/爽律 Skill执行器.py" plan   --task "处理这个事项"   --skill "合同与交易工作"   --out /tmp/plan.json
```

路由分值只是关键词辅助，不是法律结论，也不是概率或置信度。Agent 在具备更强语义理解时，应优先自行判断主技能，再把结果传给执行器。

`--structured-review` 用于明确本次任务需要多文件/跨来源结构化审阅。执行器也会根据“多文件、批量、卷宗、多版本”等任务描述进行辅助识别，但语义判断应由 Agent 负责。

`--strategy-choice` 用于明确本次存在需要比较的策略/行动选项。工程层只生成执行约束，不替用户作 C 级决定。

## 2. 生成动态清单

```bash
python "05_工程执行层/工具/爽律 Skill执行器.py" checklist   --plan /tmp/plan.json   --out /tmp/checklist.md
```

## 3. 初始化执行状态

```bash
python "05_工程执行层/工具/爽律 Skill执行器.py" init-state \
  --plan /tmp/plan.json \
  --out /tmp/state.json
```

Agent 在实际工作过程中更新清单状态、现行法核验、对抗审查、人工升级、外部处理和交付状态。

## 4. 执行质量门控

先按照 `05_工程执行层/数据结构/工程执行状态.schema.json` 形成状态文件，然后：

```bash
python "05_工程执行层/工具/爽律 Skill执行器.py" validate   --state /tmp/state.json   --out /tmp/gate-report.json
```

返回：
- `PASS`；
- `PASS_WITH_WARNINGS`；
- `BLOCKED`。

`PASS` 只表示记录中的关键执行条件已满足，不代表实体法律结论已经由律师确认正确。


## 全链路溯源检查

准备一个符合 `02_公共接口/数据结构/全链路溯源包.schema.json` 的 JSON 后，可执行：

```bash
python "爽律 Skill执行器.py" trace-check --bundle provenance.json --out provenance-report.json
```

该命令检查对象 ID 是否存在、重要结论是否存在上游支撑、已核验法律是否有定位、INFERRED 事实是否有推断依据等。它不判断实体法律结论是否正确。


## 跨模块执行检查

准备一个符合 `02_公共接口/数据结构/跨模块执行包.schema.json` 的 JSON 后，可执行：

```bash
python "爽律 Skill执行器.py" chain-check --bundle chain.json --out chain-report.json
```

该命令检查：研究请求是否回到问题、研究结果是否完成回填、策略选项和人工决定是否断链、对抗性审查是否真正产生修订或说明维持理由、需要回写的事项是否仍然开放。它不判断实体法律观点或策略优劣。

## 事项工作模型检查

```bash
python "爽律 Skill执行器.py" model-check --bundle "跨模块执行包.json" --out "事项工作模型检查.json"
```

`model-check` 只检查 TaskProfile、事项工作模型、问题树、审阅问题集、权威图谱、类案矩阵、论证地图、对象候选、计划确认和行为契约记录的结构/引用，不判断法律观点正确性。


## capability-check｜运行能力解析

当执行计划需要法律数据库/官方信源、用户知识库、OCR、DOCX/PDF 或原生修订模式时，可先准备 `RuntimeCapabilityProfile`，再执行：

```bash
python "爽律 Skill执行器.py" capability-check \
  --plan /path/to/plan.json \
  --profile /path/to/runtime-capability.json \
  --out /path/to/capability-report.json
```

该命令只对照能力档案与任务需求，不会测试第三方服务当前网络状态，也不会自动取得敏感材料外发授权。

`plan` 新增可选参数：`--private-knowledge`、`--professional-legal-source`、`--need-ocr`、`--need-docx`、`--need-pdf`、`--native-track-changes`。
