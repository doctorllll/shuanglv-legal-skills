# 质量门控规则

## 一、目的

质量门控用于确认“爽律 Skill 要求的重要步骤是否真实完成”。它不评价律师观点是否必然正确，也不替代人工专业复核。

## 二、门控结果

- `PASS`：未发现阻断项，可以进入下一交付阶段；
- `PASS_WITH_WARNINGS`：没有阻断项，但存在应在交付中保留的限制或风险；
- `BLOCKED`：存在未解决的关键问题，不应作为正式完成结果交付。

## 三、默认阻断项

以下情形原则上直接 `BLOCKED`：

1. 没有确定唯一主技能；
2. 任务要求核验现行法，但未完成实际核验；
3. 重要任务尚未完成可审计的分析与推理工作；
4. 重要任务要求对抗性审查，但没有完成；
5. 存在 C/D 级人工升级事项尚未解决；
6. 使用第三方外部服务处理敏感材料，但没有明确授权；
7. 正式交付要求输出契约检查，但尚未完成；
8. 法律研究处于 `INCOMPLETE` / `BLOCKED`，却仍准备给出无保留确定结论；
9. 声称已经审阅的关键材料无法确认实际审阅范围；
10. 本次明确需要结构化审阅，但关键材料仍以无结构摘要代替，无法追踪来源、冲突和关联问题；
11. 声称具备原生修订、OCR、页码定位等能力，但运行能力并未验证支持；
12. 重要任务存在核心结论无法回到事实、证据、法律/案例和论证记录；
13. 存在 `INFERRED` 事实但没有记录推断依据；
14. 法律规则标记 `VERIFIED_CURRENT`，但没有权威来源、精确定位或核验时间；
15. 正式交付存在重要事实/法律/分析命题，但无法关联上游分析对象；
16. 复杂任务要求跨模块执行，但研究、分析、策略或审查之间没有形成可回查交接；
17. 业务技能调用法律研究，但没有形成明确研究请求或没有记录研究结果回填；
18. 重要任务完成了对抗性审查，但没有修订受影响结论，也没有说明维持原结论的理由；
19. 明确存在多个策略选项但没有完成可比的选项分析，或存在未解决的人工决定节点；
20. 存在尚未应用的回写事件，却继续使用旧分析进入正式交付。

## 四、警告项

以下情形通常形成 `PASS_WITH_WARNINGS`，除非任务性质要求升级为阻断：

- 材料已审阅但来源定位不完整；
- 存在非关键材料未审阅；
- 存在事实或法律问题仍为 `UNKNOWN` / `DISPUTED`；
- 需要的辅助工具只能降级实现；
- 研究已满足当前任务但仍存在已明确披露的边界；
- 非关键命题存在部分溯源，但不会改变当前交付的核心结论。

## 五、硬规则

- `RECEIVED ≠ REVIEWED`；
- `ALLEGED / INFERRED / UNKNOWN ≠ VERIFIED`；
- “加载了法律研究技能” ≠ “完成了现行法核验”；
- “执行器返回 PASS” ≠ “律师已经确认结论正确”；
- API Key 存在 ≠ 获得当前材料外发授权；
- 工具理论支持 ≠ 本次能力已验证；
- “有参考资料” ≠ “结论已经完成全链路溯源”；
- “找到相关法条/案例” ≠ “已经说明该来源为何支持本案结论”。


## 六、跨模块门控

- `GATE-CROSS`：跨模块交接和回写状态；
- `GATE-HANDOFF`：业务技能与法律研究之间的请求—结果交接；
- `GATE-ADV-WRITEBACK`：对抗性审查是否真正影响或确认原结论；
- `GATE-OPTION`：存在策略选择时是否形成选项比较和人工节点；
- `GATE-WRITEBACK`：是否仍存在未处理的回写事件。

## 事项工作模型门控

当前包含事项工作模型、任务配置、问题树、审阅问题集、权威图谱、类案矩阵、计划确认和技能行为契约的条件门控。只有满足触发条件时才阻断；简单任务不因未建立完整工作模型而失败。


## 外部能力门控

当任务明确依赖专业法律信源、用户知识库、OCR、特定文件输出或原生修订模式时，应先完成能力解析。关键能力未满足、指定知识库未实际访问、或原生能力被虚假声称时，正式交付应被阻断。
