# external-processing-风险-gate（外部处理风险门控） V0.1

**适用：任何拟将用户文件、音频、视频、图片、文本或其片段发送到当前可信环境之外的第三方模型/API。**

## 1. Hard 门控

在调用第三方云服务前，必须先向用户说明并取得明确授权。

**不得：**
- 静默上传；
- 因用户已配置API Key就推定同意本次上传；
- 本地失败后自动切换外部云；
- 在未核验供应商当前政策时声称“绝不留存/一定在境内/一定不用于训练”。

## 2. 告知内容

至少说明：

```text
provider / service
what files or data will be transmitted
processing purpose
whether full file or extracted fragment is transmitted
possible confidentiality / personal information / trade secret / case-material risk
provider-side logging / caching / retention = provider-specific / verify current policy
data-location / cross-border = provider-specific / verify current configuration
possible API fees
recognition/model error risk
available local/user-controlled alternatives
```

## 3. 数据敏感等级

```text
PUBLIC
INTERNAL
CLIENT_CONFIDENTIAL
PERSONAL_INFORMATION
SENSITIVE_PERSONAL_INFORMATION
TRADE_SECRET
LEGAL_CASE_MATERIAL
UNKNOWN_HIGH
```

敏感等级越高，默认越优先 Local / User-controlled。

## 4. Consent

授权应至少绑定：
- 服务商
- 用途
- 文件/批次
- 处理方式
- Date/Session

如 服务商、用途或发送范围变化：
> 重新授权。

## 5. API 凭证

技能可以指导用户：
- 注册供应商账户；
- 创建最小权限API 凭证；
- 配置环境变量 / Secret Store；
- 测试连接。

但不得要求将长期API Secret写入：
- 技能包；
- 测试日志；
- 案件目录；
- 普通Markdown配置；
- 可被模型反复回显的正文。

## 6. 用户提示模板

> 当前 Agent 无法在本地可靠完成该文件的【OCR/音频转录/视频识别】。如果使用【第三方服务名称】，需要将【文件/片段】发送至该服务处理。这可能涉及客户秘密、个人信息、案件材料或商业秘密；供应商的日志、留存、数据位置和费用取决于其当前服务政策与配置，处理结果也可能存在识别错误。你可以选择本地方案、使用你已有的处理 技能，或授权本次外部处理。

用户必须明确选择后才能继续。
