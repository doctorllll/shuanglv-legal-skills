# Interop｜Least Necessary Disclosure

`unit_id: unit.interop.disclosure`

**Scope：** Least-necessary cross-skill/tool disclosure.

## Trigger
- A subtask/context is passed to another skill/tool.

## Negative Trigger
- No cross-boundary handoff.

## Essential Procedure
1. Select only subtask-relevant facts/results/material.
2. Exclude unrelated matter/user context.

## Deepening Conditions
- Sensitive/cross-matter data.

## Exit Sufficiency
- Recipient has sufficient context and no unnecessary disclosure.

## Professional Results
- minimal disclosed context


## Context Projection Contract

- Least Necessary Disclosure.
- Pass only subtask-relevant legal context.
- Never pass another matter by default.
- External processor consent remains separately required.

## Handoff Result

- Reuse shared professional results rather than recomputing when CURRENT.
- Cross-domain RiskResult stays matter-scoped and source-linked.
