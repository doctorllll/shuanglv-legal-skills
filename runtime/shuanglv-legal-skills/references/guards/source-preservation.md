# Guard｜Source Preservation

`unit_id: unit.guard.source-preservation`

**Scope：** Original-source preservation guard.

## Trigger
- Task would modify an original legal/evidence source.

## Negative Trigger
- Editing a derivative/copy.

## Essential Procedure
1. Keep original immutable by default.
2. Create/edit derivative where possible.
3. Require explicit original-mutation authority if unavoidable.

## Deepening Conditions
- Evidence/legal source with authenticity significance.

## Exit Sufficiency
- Original remains preserved or authorized mutation is explicit and auditable.

## Professional Results
- original/derivative mutation state


## Source Preservation Contract

- Original legal/evidence source immutable by default.
- Prefer derivative edits.
- Original mutation requires explicit authority and an actual capability that can preserve auditability.
